# data/

Generated by `code/prep_intel.py` from the Intel Berkeley Research Lab data
(https://db.csail.mit.edu/labdata/labdata.html, `data.txt`):

```bash
python3 -I code/prep_intel.py /path/to/data.txt data                     # main window
python3 -I code/prep_intel.py /path/to/data.txt data 2004-03-10 _heldout  # held-out window
```

Files: `intel_temp_1min*.npy` (minutes x motes, gaps linearly interpolated),
`intel_mask_1min*.npy` (True = minute with a recorded reading), `intel_summary*.json`.
The expected summaries: main window 2004-02-29, 28 motes, 89.9% of mote-minutes observed;
held-out window 2004-03-12, 8 motes, 84.1% observed.
